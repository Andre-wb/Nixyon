# Артефакты тестирования

[`results.csv`](results.csv): результаты собственных замеров, одна строка на запись или
набор. Методика и таблицы: [`docs/TEST_RESULTS.md`](../../docs/TEST_RESULTS.md).

| Колонка | Значение |
|---|---|
| `test_id` | имя замера |
| `date` | дата замера |
| `commit` | коммит кода, если записан |
| `tool` | `eval`, `quality_eval` или приложение на Android |
| `dataset`, `record` | набор и запись |
| `language` | язык речи: `ru`, `en` или `auto` (определяется по записи) |
| `audio_seconds` | длина звука, с |
| `speaker_count_mode` | `auto`: число говорящих оценивает приложение |
| `speakers_truth`, `speakers_found` | говорящих по эталону и найдено |
| `wer_percent`, `cer_percent`, `der_percent` | метрики, % |
| `rtf` | время обработки, делённое на длину звука |
| `device` | где шёл замер |
| `notes` | подробности |

Пустая ячейка значит, что эта величина в замере не считалась или не записана. Числа с
точкой в качестве разделителя дробной части.
