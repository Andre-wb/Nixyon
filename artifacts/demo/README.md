# Материалы демонстрации

## Видео

### Первое видео

[nixyon-demo-1.mp4](nixyon-demo-1.mp4): 3 мин 17 с, 1280×720, 76 МБ. Телефон с приложением
снят на отдельную камеру, запись идёт с микрофона телефона.

| Время | Что показано |
|---|---|
| 0:00 | на телефоне включается режим полёта: сеть выключена |
| 0:10 | запись с микрофона: с ноутбука играет тестовая запись, на телефоне идёт запись |
| 1:05 | расшифровка встречи: участники, кто когда говорил, реплики со временем |
| 1:15 | проверка фразы: повторное распознавание реплики, «было» и «стало» |
| 1:45 | слова-паразиты: в выбранных фразах или во всём диалоге |
| 2:00 | плеер: подсветка слов, перемотка на 10 с, скорость, участник, пропуск тишины; правка текста реплики |
| 2:30 | краткое содержание от языковой модели на телефоне |
| 2:55 | экспорт: выбор формата, «Сохранить файл», «Поделиться» |
| 3:10 | статистика встречи |

Режим полёта включается в начале видео, до записи.

| 1:03 | реплики с эмоциями, у одного участника имя «Александр» |
| 1:10 | пометка «Говорят одновременно», плеер |
