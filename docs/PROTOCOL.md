# Формат результата

В решении нет протокола передачи данных: всё считается на одном устройстве. Здесь описан
формат результата, который приложение отдаёт наружу, и внутренний формат расшифровки, из
которого он строится.

## Цели

- JSON-вывод точно в формате задания: текст реплики, идентификатор говорящего, время начала
  и окончания в миллисекундах.
- Один источник истины на устройстве: все экспорты (TXT, Markdown, SRT, JSON, DOCX, PDF)
  строятся из внутренней расшифровки.

## JSON-вывод

Экспорт «JSON» в приложении. Код: [`nixyon-render/src/json.rs`](../nixyon-render/src/json.rs),
эталон: [`nixyon-render/tests/golden/export.json`](../nixyon-render/tests/golden/export.json).

| Поле | Тип | Значение |
|---|---|---|
| `transcript` | array | реплики по времени начала |
| `speaker_id` | string | `speaker_` и номер говорящего из расшифровки |
| `start_ms` | integer | начало реплики, мс от начала записи |
| `end_ms` | integer | конец реплики, мс от начала записи |
| `text` | string | текст реплики |

Правила:

- одна запись на реплику, других полей нет: ни имён, ни слов, ни флагов, ни метаданных;
- `speaker_id` не меняется при переименовании говорящего; после слияния двух говорящих
  номера могут идти с пропуском;
- время округляется до ближайшей миллисекунды, отрицательное время становится 0, конец не
  раньше начала;
- `text` без пробелов по краям. Пометки «[неразборчиво]» и «(?)» в JSON не пишутся. У
  реплики, где голос слышен, но слова не распознаны, `text` пустой;
- реплики идут по времени начала, при равном начале в порядке расшифровки.

## Внутренний формат расшифровки

Тип `Transcript` в [`nixyon-core/src/transcript.rs`](../nixyon-core/src/transcript.rs),
`schema_version` 1. Файл другой версии не читается.

| Поле | Значение |
|---|---|
| `schema_version` | версия формата, 1 |
| `created_at` | время создания, UTC |
| `audio` | имя файла, длительность в секундах, частота |
| `engine` | модели поиска речи, распознавания и голоса |
| `language` | язык речи записи, `ru` или `en`; без поля читается как `ru` |
| `speakers` | номер, имя, время речи, число реплик и слов; `age` и `gender`, если модель уверена |
| `turns` | реплики: номер, говорящий, начало и конец в секундах, текст, слова со временем, флаги, `emotion` |

Флаги реплики:

- `overlap`: в реплике накладываются голоса;
- `unclear`: голос слышен, а текст распознан не весь или не распознан совсем;
- `speaker_unsure`: голос мало похож на говорящего реплики;
- `clipping`: в звуке перегрузка.

В расшифровке хранится номер говорящего. Подпись «Спикер N» или «Speaker N» подставляют
экспорты на языке интерфейса, если у говорящего нет имени.

## Пример

```json
{
  "transcript": [
    { "speaker_id": "speaker_1", "start_ms": 1250, "end_ms": 4380, "text": "Добрый день!" },
    { "speaker_id": "speaker_2", "start_ms": 4610, "end_ms": 6020, "text": "Здравствуйте." }
  ]
}
```
