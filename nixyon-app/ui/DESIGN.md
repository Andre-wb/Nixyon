# Nixyon — Dark Ambient Futurism

Единая визуальная среда приложения: тёмный графит, мягкий синий свет, стеклянные
поверхности и спокойная типографика. Оформление не зависит от системной светлой/тёмной
темы — это осознанное свойство продукта, а не отсутствие настройки.

Версия интерфейса: **1.6**. Дизайн собран поверх свежего релиза движка: экраны и жесты
прежние, к ним добавлены архив встреч, метки, модели, слова-паразиты, эмоции реплик,
полный плеер и настройки. Вход и регистрация убраны — приложение работает локально.

## 1. Палитра

| Токен | Значение | Назначение |
| --- | --- | --- |
| `--bg` | `#101112` | основной фон |
| `--bg-secondary` | `#191C20` | вторичный фон, углубления |
| `--surface` | `#20242A` | карточки, непрозрачный fallback |
| `--surface-elevated` | `#252A32` | поднятые поверхности |
| `--accent` | `#5799E8` | основной синий акцент |
| `--accent-soft` | `#8BBEFF` | текст-акцент, подсветка, фокус |
| `--text` | `#E8EBF0` | основной текст |
| `--text-secondary` | `#9299A5` | подписи, метаданные |
| `--border` | `rgba(255,255,255,0.09)` | тонкие границы |
| `--success` | `#64B99B` | статус «локально» |
| `--error` | `#E87979` | ошибки и опасные действия |

Синий — акцент, а не фон. Основные заливки: `--accent-fill: #2F6FBE` и градиент
`#3272C6 → #2A5FA8`; белый текст на нём даёт контраст выше 4,5:1.
Опасная заливка — `#B85050` (белый текст 4,88:1). Текст и управляющие элементы
проверяются тестом `src-tauri/tests/contrast.rs`.

Цвета участников — приглушённая категориальная палитра (`--speaker-1…8`), всегда
сопровождается именем, поэтому цвет не является единственным носителем смысла.
Эмоции реплик (`--emotion-joy … --emotion-disgust`) взяты из той же семьи: точка рядом
с подписью только дублирует текст, который и несёт смысл.

## 2. Типографика

Основной шрифт — **Manrope** (variable, 400–800), локально в `ui/fonts/` с SIL OFL.
Fallback: Inter → Onest → Segoe UI → system-ui.

| Роль | Размер | Начертание |
| --- | --- | --- |
| Hero / крупный заголовок | 33–44 px | 700, −0.04em |
| Заголовок экрана | 28–34 px | 700, −0.035em |
| Заголовок карточки | 15–18 px | 600 |
| Body | 15–16 px | 400, 1.5–1.65 |
| Вторичная подпись | 12–13 px | 400–500 |
| Micro label | 10–11 px | 600, 0.14–0.22em, uppercase |

Заголовки используют `text-wrap: balance`, длинный текст — `pretty`; переносы не
ломают ритм. Крупные заголовки не получают фокусную рамку при программном фокусе.

## 3. Атмосфера

Постоянный слой `.ambient` находится за всеми экранами:

- глубокий графитовый градиент и три мягких радиальных источника света;
- четыре стеклянные 3D-сферы, частично выходящие за границы экрана;
- независимые анимации дрейфа 15–26 с с изменением масштаба и прозрачности;
- тонкие контурные волны SVG по нижнему краю и мягкая сетка линий сверху;
- SVG-шум с прозрачностью 2,8 % и виньетка для читаемости.

Сферы и свечения малоконтрастны: атмосфера не конкурирует с текстом. При
`prefers-reduced-motion` анимации отключаются, при `prefers-contrast: more` фон
приглушается.

## 4. Стекло и поверхности

- фон стекла: 3,2–6,5 % белого;
- граница: 9 % белого, у важных слоёв — 15 %;
- `backdrop-filter: blur(22px) saturate(125%)` (листы — 28 px);
- радиусы: 15–18 px для контролов, 24 px для карточек, 30 px для нижних листов;
- мягкая тень без жёстких краёв;
- стекло используется только для важных контейнеров: панель участников, карточки
  встреч, плеер, листы, поиск. Список реплик и таблицы моделей остаются на обычных
  поверхностях.

Fallback: при отсутствии `backdrop-filter` или при `prefers-reduced-transparency`
используется непрозрачный `--surface`.

## 5. Компоненты

**Кнопки.** Primary — синий градиент, высота 52, радиус 16, внутренний блик и мягкое
свечение. Secondary — графитовое стекло с тонкой границей. Plain — текстовая кнопка
без фона. Danger — приглушённый красный. Все интерактивные цели — не меньше 48×48 dp.

**Поле записи.** Центральная сфера 112 px с мягким 3D-объёмом, двумя орбитами и
дышащим свечением. В покое — синяя, при записи — красная; кольцо уровня звука
реагирует на микрофон. В режиме записи hero и настройка участников плавно уходят,
остаются таймер, кнопка паузы и живой черновик.

**Архив встреч.** Список — одна стеклянная карточка со строками: название (или дата и
время), длительность и участники. Поиск по всем встречам показывает совпадения с
подсветкой и контекстом, метки фильтруют список чипами. Карточка «Продолжить» над
списком — встреча, которую открывали последней; если её ещё не было, карточки нет.

**Иконки.** Единый outline-стиль, stroke 1.8, скруглённые концы; Lucide/Phosphor-
подобная геометрия. Эмодзи не используются.

**Листы.** Нижние sheets с ручкой, стеклянным фоном, радиусом 30 сверху и учётом
safe-area. Выбор форматов и языков — сетка стеклянных radio-карточек. Опасные
действия — отдельные модальные окна с красной кнопкой.

**Переключатели и модели.** Строка модели: название, описание и размер слева,
переключатель 52×32 справа. Обязательная модель и уже скачанная показывают надпись
вместо переключателя. Прогресс загрузки — тонкая полоса под списком.

**Плеер.** Плавающая стеклянная панель в две строки: перемотка −10/+10, play/pause и
время; ниже — скорость (0,75×–2×), выбор участника и «без тишины». Высота панели
следит за переносом строк (`ResizeObserver` → `--player-height`), поэтому последняя
реплика не уходит под неё.

**Реплика.** В шапке: имя, время, метка эмоции, перепроверка распознавания и правка
текста. Эмоция меняется листом выбора, ответ модели показывается как текст —
никогда как разметка. Слова-паразиты сначала предлагаются списком правок и только по
кнопке «Заменить» попадают в текст.

## 6. Движение

| Слой | Длительность | Кривая |
| --- | --- | --- |
| Нажатие | 160 ms | `cubic-bezier(.32,.72,0,1)` |
| Состояния, hover | 220 ms | та же |
| Появление экрана | 460 ms + stagger 35 ms | `cubic-bezier(.22,1,.36,1)` |
| Нижний лист | 320 ms | та же |
| Дрейф сфер | 15–26 s | ease-in-out, alternate |
| Дыхание света | 6–24 s | ease-in-out |

На экране действует мягкий fade + translateY; никаких резких слайдов. Для
`prefers-reduced-motion: reduce` все анимации и переходы сокращаются до 1 ms.

## 7. Экраны

1. **Первый запуск (мини-обучение)** — логотип, карточка с тремя шагами работы,
   кнопка «Продолжить» и подпись «только на этом устройстве». Входа, профиля и PIN
   нет: приложение локальное. Инструкция открывается снова из настроек.
2. **Home** — бренд, статус «Локально», hero, число участников, центральная запись,
   импорт, карточка «Продолжить», голоса, архив встреч с поиском и метками, offline-подпись.
3. **Recording** — focus mode с таймером, паузой, уровнем и живым текстом.
4. **Processing** — орбитальная визуализация, фаза, тонкий progress, отмена.
5. **Transcript** — название и метки встречи, участники, таймлайн, действия, поиск,
   карточки реплик с эмоцией и перепроверкой, плеер, удаление встречи.
6. **Voices** — библиотека голосов; нажатие на голос открывает встречи, где он узнан.
7. **Models** — экран загрузки моделей с размерами, переключателями и прогрессом.
8. **Settings** — язык, модели, место на телефоне, срок очистки звука, слова и имена,
   повторный показ инструкции.
9. **Sheets** — настройки участника, название встречи, метки, экспорт, статистика,
   протокол, имена, правка и удаление реплики, эмоция, перепроверка, слова-паразиты,
   голос и его встречи, подтверждения удаления и очистки.

## 8. Android и доступность

- `viewport-fit=cover`, edge-to-edge, safe-area для top/bottom/left/right;
- полупрозрачный верхний scrim сохраняет читаемость часов и значков;
- системные бары переводятся в тёмный режим через `set_system_bars`;
- адаптив 320–800+ px без горизонтального скролла (проверено `preview/audit.mjs`);
- все touch-targets ≥ 48 dp, `:focus-visible` только для клавиатуры;
- контраст текста ≥ 4,5:1, нетекстовых элементов ≥ 3:1;
- `prefers-contrast`, `prefers-reduced-transparency`, `prefers-reduced-motion`;
- диалоги фокусируются сами, а не первую кнопку, чтобы не рисовать случайную рамку;
- на узком экране действия в шапке расшифровки переносятся на отдельную строку.

## 9. Логотип и аватар

**Знак.** Минимальный силуэт пера из звуковых волн: цельный силуэт опахала с
пятью вертикальными вырезами-волнами и очин (стержень), выходящий за силуэт вниз-влево.
Один градиент от `#4F90DE` к `#EDF6FF`, без обводки и без лишних деталей. На 27 px в
шапке и 39 px на первом запуске читается как самостоятельный знак. Знак встроен
SVG-символом `#feather-mark` и не зависит от внешних файлов.

**Иконка приложения** собирается из того же знака: adaptive-иконка (тёмный фон со
свечением и векторное перо в safe zone), PNG mdpi–xxxhdpi для старых лончеров и
отдельная круглая версия. Для desktop-сборки обновлён набор `nixyon-app/src-tauri/icons`.
Круглая версия `artifacts/avatar-feather-512.png` — аватар профиля.

Источники: `preview/icon.html` (1024 px) и `preview/ic_launcher_foreground.xml`
(векторная иконка). `preview/capture-icon.mjs` рендерит слои, `preview/make_icons.py`
раскладывает их по плотностям и в набор Tauri.

## 10. Тема, вход и данные

Тема одна — тёмная ambient-среда. Переключателя «Авто / Светлая / Тёмная» нет
намеренно: вторая палитра означала бы второй прогон контраста и другой характер
продукта. Входа по PIN, профиля и блокировки по отпечатку в интерфейсе тоже нет:
данные не шифруются паролем, приложение не просит входить и всё считает на телефоне.
Первый запуск объясняет это тремя шагами вместо формы входа.

## 11. Файлы

- `nixyon-app/ui/styles.css` — вся визуальная система, первый запуск и адаптив;
- `nixyon-app/ui/index.html` — ambient-слой, SVG-знак и семантическая разметка экранов;
- `nixyon-app/ui/js/onboarding.js` — первый запуск вместо входа, флаг «показано»;
- `nixyon-app/ui/js/app.js` — порядок запуска экранов и истории;
- `nixyon-app/ui/js/{home,meetings,meeting-search,meeting-title,label-filter,labels}.js` —
  главный экран, архив встреч, поиск, метки;
- `nixyon-app/ui/js/{transcript,player,playback-spans,search,timeline,turn-text,emotion,fillers}.js` —
  расшифровка, плеер, поиск, эмоции, слова-паразиты;
- `nixyon-app/ui/js/{models,settings,settings-models,settings-storage}.js` — модели,
  настройки, место на телефоне;
- `nixyon-app/ui/js/{voices,stats,summary,names,export,processing}.js` — голоса,
  статистика, протокол, имена, экспорт, обработка;
- `nixyon-app/ui/js/theme.js` — единая тёмная среда и системные бары;
- `nixyon-app/ui/fonts/` — Manrope + лицензия OFL;
- `nixyon-app/ui/generated/i18n.js` — модуль словарей; строится `preview/build_i18n.py`
  так же, как `src-tauri/build.rs`;
- `nixyon-app/src-tauri/tauri.conf.json` — CSP для динамических CSS-переменных;
- `nixyon-app/src-tauri/icons/` — набор иконок приложения;
- `preview/` — локальный harness с mock Tauri API, рендером иконки и визуальной
  проверкой (`audit.mjs`, `smoke.mjs`, `snap.mjs`);
- `artifacts/` — исходники иконок, аватар и скриншоты ключевых экранов;
- `dist/` — design-preview APK и его описание.
