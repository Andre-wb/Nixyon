# Тестовые встречи для замера языковой модели

Синтетические расшифровки: тексты написаны для замера, это не записи настоящих встреч.
Формат как у экспорта TXT приложения. Рядом с каждой встречей `*.expected.json`:
задачи (исполнитель, суть, срок, слова для поиска), решения, факты и ловушки, которых в
ответе быть не должно (отменённые поручения, имена, которых нет в разговоре).
